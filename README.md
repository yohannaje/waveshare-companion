# Compañero del Waveshare

Firmware para el Waveshare ESP32-S3-Touch-LCD-1.54: personaje en pixel art que vive en 4 ambientes (baño, cocina, living, patio) según la hora, escucha solo mientras se mantiene apretado el botón + y contesta con sonidos de ardilla.

- Instalar: abrir la página de GitHub Pages de este repo en Chrome y tocar "Instalar".
- Se compila solo con GitHub Actions en cada cambio (gratis).
- Sin datos personales en el repo: el WiFi se carga en la placa.
